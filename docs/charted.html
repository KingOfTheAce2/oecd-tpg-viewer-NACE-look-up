Charted - by A.C. van der Linde

This repository includes the source code for the Charted application in the docs/assets/charted_app/ folder. To run the Flask app locally install the dependencies and execute python docs/assets/charted_app/app.py.

pip install flask flask_session pandas sqlalchemy pydantic
python docs/assets/charted_app/app.py

The application will start on http://localhost:5000/.
